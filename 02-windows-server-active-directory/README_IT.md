# 02 — Windows Server & Active Directory

## Obiettivo

Costruire e amministrare un ambiente Microsoft domain realistico usando Windows Server 2025.

## Lab pianificati

- installazione Windows Server e baseline configuration
- configurazione IPv4 statica e DNS
- deployment AD DS e DNS
- creazione del dominio
- utenti, gruppi e Organizational Units
- domain join di un client Windows
- Group Policy
- DHCP
- file services e permessi
- FSMO roles
- controller di dominio aggiuntivo
- troubleshooting account lockout
- security auditing con Event Viewer
- Remote Desktop Services
- basi IIS
- amministrazione PowerShell

Questa sarà una delle sezioni più importanti del portfolio per colloqui da **Junior System Administrator**.
